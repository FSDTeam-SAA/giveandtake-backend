Future catalogue changes
Use Admin > Plan > Edit price > Save changes. Update company and recruiter
separately if both should match. No code deployment is needed for a price
change. Existing purchases preserve their recorded price and credits.

If PAYG restoration is needed elsewhere, preview with npm run restore-job-payg,
then apply with npm run restore-job-payg -- --apply after reviewing a backup.
The focused script preserves active PAYG credit plans with admin customisations.
Do not rerun the original full package migration after customising prices.
